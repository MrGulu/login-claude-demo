# 登录审计看板需求规范 (Login Audit Dashboard Specification)

## 目的 (Purpose)
提供系统登录活跃度数据可视化监控与详细日志的审计功能。

## 需求 (Requirements)

### Requirement: 首页大盘数据图表展示
系统 SHALL 允许所有已登录的用户在“首页”看板中查看可视化统计图表。图表至少包含：最近7天的用户登录活跃度折线图、登录系统所用浏览器占比饼图。

#### Scenario: 用户查看首页数据图表
- **WHEN** 用户登录系统并进入首页 (Home 页面)
- **THEN** 系统 SHALL 发起请求获取登录日志统计数据，并通过 ECharts 渲染出折线图与饼图

---

### Requirement: 登录日志分页查询与审计
系统 SHALL 提供一个“登录日志”菜单（层级与用户管理并列，隶属于系统监控或系统管理），仅允许 `root` 超级管理员角色访问，以供审计登录历史。

#### Scenario: 管理员查询登录日志列表
- **WHEN** 拥有 root 角色的管理员登录并进入“登录日志”页面，输入“用户名”或“登录状态”并点击搜索
- **THEN** 系统 SHALL 倒序分页展示对应的登录日志，每条日志需包含用户名、IP 地址、浏览器名称、操作系统、登录地点、登录状态（成功/失败）、错误消息及登录时间

#### Scenario: 普通用户尝试访问登录日志失败
- **WHEN** 非 root 角色的普通用户尝试通过输入 URL `/system/login-logs` 或直接请求登录日志 API
- **THEN** 系统 SHALL 拦截其访问，并在前端重定向或在接口处返回 403 Forbidden 权限不足错误
