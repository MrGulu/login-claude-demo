# Login System - 全栈登录系统 架构总入口

> 状态：骨架（待填充）
> 创建日期：2026-06-09

## 1. 项目简介
系统是基于 Spring Boot + Vue 3 开发的后台用户管理和权限控制示范系统。

## 2. 核心概念 / 术语表
- **用户 (User)**：系统的账号实体，可以关联角色、岗位和所属部门。
- **部门 (Department)**：系统的组织架构单元，呈树形层级结构。
- **用户所属部门 (User Department Association)**：用户与部门的多对一关联关系，每个用户至多绑定一个所属部门。

## 3. 子系统 / 模块索引
- **用户管理**：负责用户账户的增删改查、分配角色、分配岗位、以及分配所属部门。
- **角色管理**：管理系统的角色权限，支持分配菜单树的按钮访问权限。
- **岗位管理**：管理系统的岗位和职务，支持为用户分配多个岗位。
- **部门管理**：新增的核心模块，支持对部门进行层级管理（CRUD），可在新增/编辑用户时进行单选关联。

## 4. 关键架构决定
- **单选关联架构**：在 `sys_user` 实体上直加 `dept_id` 作为外键关系，满足单选所属部门的高效与简单原则，避免了中间联表带来的性能开销。

## 5. 已知约束 / 硬边界
- **级联删除硬边界**：在删除部门时，如果该部门下有子部门或者已经绑定了用户，数据库和业务层将强制拦截删除，以维护组织数据的一致性。
- **父部门防循环引用**：变更部门父级节点时，父级节点不能选择其自身或其子孙节点，防止在树渲染时造成无限死循环。
